# Mızıkçı Çay Demleme Simülatörü

Bu, dünyanın **en ciddi** ve **en gereksiz** çay demleme simülatörüdür.

## Ne Yapar?

- Çay demlemeye çalışır.
- Asla bitmez.
- Her adımda şikayet eder.
- Gerçekten çalışır (Python 3 ile).

## Kullanım

```bash
python cay_demle.py
```

Bekle, bekle, bekle... Çay hazır olmayacak ama sen bekleyeceksin. Tıpkı gerçek hayattaki gibi.

## Özellikler

- %100 mızıkçılık garantisi
- Sonsuz döngü (CTRL+C ile çık)
- Türkçe şikayet mesajları
- Gerçek zamanlı ilerleme çubuğu (yalan)

## Neden Bu Repo?

Çünkü birileri "anlamlı bir şey yap" dedi. Biz de "hayır" dedik.
